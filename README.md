# Метка — редактор таймкодов

Статический сайт без сборки, библиотек и сервера. Откройте index.html в браузере, затем выберите видео и TXT. Файлы обрабатываются локально, никуда не отправляются. Изменения выгружаются кнопкой «Сохранить TXT»; перед закрытием вкладки сохраните работу.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в GitHub.
2. Загрузите содержимое этой папки в корень репозитория: index.html, style.css, app.js и .nojekyll. Архив загружать не нужно — сначала распакуйте его.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch, затем ветку main и папку / (root). Нажмите Save.
5. После публикации ссылка появится в разделе Pages. Адрес проекта: https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/ . Для репозитория ВАШ-ЛОГИН.github.io адрес будет https://ВАШ-ЛОГИН.github.io/ .

Официальная инструкция: https://docs.github.com/en/pages/quickstart

## Формат TXT

UTF-8, одна метка на строку:

00:00:00 - Начало
00:05:20 - Вступление
00:06:50 | Другой разделитель

После времени идут ровно три символа разделителя. Они сохраняются отдельно для каждой метки без изменений. Новые метки наследуют разделитель выбранной метки (либо первой строки), а при пустом списке используют « - ». Сохраняются стиль переноса строк LF/CRLF, BOM UTF-8 и наличие заключительного переноса строки. При неправильной строке программа сообщает номер и не загружает файл частично. Метки автоматически сортируются по времени.

## Управление

- ← / →: видео на ±5 секунд. Удержание более 0,2 секунды — перемотка ×16.
- Shift + ← / →: выбранная метка на ±5 секунд без перемотки видео. Удержание — ×160 (в 10 раз быстрее перемотки видео).
- ↑ / ↓: предыдущая / следующая метка с переходом видео к её времени, без автоповтора.
- Shift + Delete: удалить метку и выбрать следующую; для последней выбирается предыдущая.
- Левый Shift + правый Shift: добавить метку в текущей позиции видео. Есть также кнопка +.
- Backspace: редактировать текст. Enter сохраняет, Escape отменяет. Остальные горячие клавиши отключены во время ввода. Выход из поля мышью тоже сохраняет текст.
- Нажатие на время: изменить время в формате ЧЧ:ММ:СС, Enter — сохранить, Escape — отменить.
- Нажатие на строку: выбрать метку и перейти к ней в видео.
- Нажатие / перетаскивание шкалы: перемотать видео.
- Пробел: воспроизведение / пауза.
- «Отменить»: отменить последнее изменение (до 100 действий).

Рекомендуется настольный браузер. На устройствах без двух клавиш Shift используйте кнопку +. Возможность воспроизведения конкретного видео зависит от кодеков браузера; обычно подходят MP4 H.264 и WebM. Реальное видео и сочетание двух физических Shift нужно проверить на вашей клавиатуре — при разработке проверены интерфейс и логика TXT, полного теста с вашим видео не было.
