# Метка — редактор таймкодов

Статический сайт без сборки, библиотек и сервера. Откройте index.html в браузере, затем выберите видео и TXT. Файлы обрабатываются локально, никуда не отправляются. Изменения выгружаются кнопкой «Сохранить TXT»; перед закрытием вкладки сохраните работу.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в GitHub.
2. Загрузите содержимое этой папки в корень репозитория: index.html, style.css, app.js и .nojekyll. Архив загружать не нужно — сначала распакуйте его.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch, затем ветку main и папку / (root). Нажмите Save.
5. После публикации ссылка появится в разделе Pages. Адрес проекта: https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/ . Для репозитория ВАШ-ЛОГИН.github.io адрес будет https://ВАШ-ЛОГИН.github.io/ .

Официальная инструкция: https://docs.github.com/en/pages/quickstart

## Формат TXT

UTF-8, одна метка на строку:

00:00:00 - Начало
00:05:20 - Вступление
00:06:50 | Другой разделитель

После времени идут ровно три символа разделителя. Они сохраняются отдельно для каждой метки без изменений. Новые метки наследуют разделитель выбранной метки (либо первой строки), а при пустом списке используют « - ». Сохраняются стиль переноса строк LF/CRLF, BOM UTF-8 и наличие заключительного переноса строки. При неправильной строке программа сообщает номер и не загружает файл частично. Метки автоматически сортируются по времени.

## Управление

- ← / →: видео на ±5 секунд. Удержание более 0,2 секунды — перемотка ×16.
- Shift + ← / →: выбранная метка на ±5 секунд без перемотки видео. Удержание — ×160 (в 10 раз быстрее перемотки видео).
- ↑ / ↓: предыдущая / следующая метка с переходом видео к её времени, без автоповтора.
- Shift + Delete: удалить метку и выбрать следующую; для последней выбирается предыдущая.
- Левый Shift + правый Shift: добавить метку в текущей позиции видео. Есть также кнопка +.
- Backspace: редактировать текст. Enter сохраняет, Escape отменяет. Остальные горячие клавиши отключены во время ввода. Выход из поля мышью тоже сохраняет текст.
- Нажатие на время: изменить время в формате ЧЧ:ММ:СС, Enter — сохранить, Escape — отменить.
- Нажатие на строку: выбрать метку и перейти к ней в видео.
- Нажатие / перетаскивание шкалы: перемотать видео.
- Пробел: воспроизведение / пауза.
- «Отменить»: отменить последнее изменение (до 100 действий).

Рекомендуется настольный браузер. На устройствах без двух клавиш Shift используйте кнопку +. Возможность воспроизведения конкретного видео зависит от кодеков браузера; обычно подходят MP4 H.264 и WebM. Реальное видео и сочетание двух физических Shift нужно проверить на вашей клавиатуре — при разработке проверены интерфейс и логика TXT, полного теста с вашим видео не было.

## Автоматические метки по речи

В редакторе одного видео откройте файл, в панели «Автоматические метки» введите собственный API-ключ Groq (https://console.groq.com/keys) и нажмите «Проанализировать видео». Аудио и расшифровка отправляются в Groq; сам ключ используется только для запросов к api.groq.com, не записывается в репозиторий, localStorage или журнал и остаётся только в памяти вкладки.

Сайт сам извлекает первую аудиодорожку через локальный FFmpeg WASM, преобразует в 16 кГц моно PCM и делит на 300-секундные фрагменты с перекрытием 2 секунды. Размер WAV — около 9,6 МБ, ниже лимита Groq 25 МБ. Whisper Large V3 возвращает речь с временными отметками, GPT-OSS 20B через Groq выделяет темы. Время названий берётся только из существующих сегментов расшифровки. Метки добавляются к существующим, одинаковые названия в пределах двух секунд не дублируются. Проверьте результат и сохраните TXT.

Тишина определяется локально по RMS с окнами 20 мс. Интервалы от 15 секунд отмечаются предупреждением с началом, концом и длительностью. Стандартный порог −45 dBFS; можно выбрать −50 или −35 dBFS. Это детектор низкого уровня сигнала, а не доказательство технической неисправности: пауза в речи также может быть тишиной, а фоновый шум способен скрыть пропажу голоса. Учитываются интервалы на границах фрагментов и в конце файла. Видео без аудиодорожки получает отдельную предупреждающую метку без отправки запросов в API.

Есть прогресс, остановка, ограниченные повторы сетевых/временных ошибок и ожидание при 429. При остановке/ошибке уже полученные метки и обнаруженная тишина обработанной части сохраняются. Повторный запуск начинает анализ с начала. Бесплатность зависит от плана и квот вашего Groq-аккаунта; при платном плане запросы могут тарифицироваться. Непрерывная работа требует открытой вкладки и подключения к сети. Для первого запуска обработчик загружает около 10 МБ (сжатая загрузка; после распаковки около 32 МБ). Он размещён вместе с сайтом, без runtime CDN.

Обработка ограничена файлами до 1 ГБ, но на устройствах с малым объёмом памяти и они могут не поместиться: FFmpeg хранит входной файл в памяти. Требуется современный настольный браузер с WebAssembly и Worker. Часть форматов воспроизводится браузером, но может не поддерживаться аудиообработчиком, и наоборот. Ручное редактирование работает без API.

### Проверки автоматизации

`node --test tests/*.test.cjs` — границы тишины, интервалы между фрагментами, точное значение 15 с, отсечение шумовых сегментов, реальные индексы времени, повтор 429, неверный ключ и отмена запроса.

`tests/ai-browser.html` — автономная проверка настоящего FFmpeg WASM в браузере с синтетическим WAV (16 с тишины), имитацией обоих ответов Groq и отдельным MP4 без аудио. Тест не отправляет данные в Groq. Реальные запросы с пользовательским ключом при разработке не выполнялись: ключ не предоставлен. Лицензии и сведения о стороннем обработчике — vendor/README.md.
