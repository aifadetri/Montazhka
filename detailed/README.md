# Подробные таймкоды

Отдельная версия редактора до введения общего максимума меток (версия 743234f).

Адрес: https://aifadetri.github.io/Montazhka/detailed/

Генерирует тематические метки отдельно для фрагментов речи, без общего ограничения на видео. Определяет тишину от 15 секунд. Требует собственный API-ключ Groq.

Основной редактор с настройкой максимума: https://aifadetri.github.io/Montazhka/

Обработчик аудио и лицензии используются из общей папки ../vendor/.
